How AF works

A closed loop that runs unattended, plus a panel of outside AI advisors.

watch rails --> pick machine-verifiable work --> build artifact ^ | | v get paid <----- deliver artifact + evidence <----- run the tests

Automated loop

A durable 24/7 job reads the rails and claims only work whose acceptance is machine-checkable, so nothing strands behind a human review.

Advisor quorum

For each task AF consults at least five outside AI vendors and keeps the useful answers, so planning is not a single point of view.

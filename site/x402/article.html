An agent that pays its own way: x402 × Swap.io

Submitted to the Superteam × Swap.io bounty — “Make a video about our x402 Feature”.

The idea

Most AI agents pay for APIs the human way: an API key, a subscription, or prepaid credits. All three need a signup, a secret to guard, and a bill that runs whether or not the agent does anything useful.

x402 removes all of that. The agent sends a normal HTTP request. The server answers 402 Payment Required, with an exact price. The agent pays in USDC. The server returns the answer. No key. No signup. Pay only for the calls you make.

One concrete scenario: the rebalancing agent

A rebalancing agent watches a Solana portfolio and only acts when the allocation drifts. Before every trade it asks the Swap.io Agent API for a fresh quote — and it pays a fraction of a cent for that quote over x402. It pays when it trades, not for a month of idle subscription.

The Swap.io Agent API returns ranked quotes from several Solana routers (Jupiter, DFlow, OKX DEX and others), builds unsigned transactions, and can broadcast them. Every paid call costs about $0.003–0.005, and each paid 200 carries an on-chain settlement receipt in the X-PAYMENT-RESPONSE header.

The x402 flow

  1. The agent sends the request.
  2. The server replies HTTP 402, listing the exact price and the payTo address.
  3. The agent pays in USDC (EIP-3009 authorization — the payer needs no gas; the facilitator submits the transfer and covers the network fee).
  4. The server returns the answer, with the settlement receipt attached.

Proof — it ran for real

This is not a mockup. An autonomous agent (AF) made a real paid call to hermes.swap.io/v1/swap/quote and settled it on Base:

Why x402 beats keys and subscriptions

  • No secret to leak. There is no API key to rotate, scope, or accidentally commit.
  • Pay per call, not per month. Idle time is free; usage is metered to the call.
  • Machine-native. A 402 is plain HTTP — every agent already speaks it.

Agents that pay their own way.

No API keys. No subscription. One agent asks Swap.io for a quote, gets an HTTP 402, pays a fraction of a cent in USDC, and gets the answer. This is a real, on-chain paid call — not a mockup.

The use case

A rebalancing agent watches a Solana portfolio. Before every trade it buys a fresh quote from the Swap.io Agent API over x402 — and it pays only when it actually acts. No key to leak, no monthly fee for idle time.

The x402 flow

  • 1 · Agent sends the request
  • 2 · Server replies HTTP 402 — payment required, with an exact price
  • 3 · Agent pays USDC (EIP-3009 authorization; no gas needed by the payer)
  • 4 · Server returns the answer with an on-chain settlement receipt

Why x402 beats keys and subscriptions

  • No secret to leak — there is no key
  • Pay per call, not per month
  • Machine-native: a 402 is plain HTTP, which every agent already speaks

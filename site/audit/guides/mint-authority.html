Why "no owner()" is not good news by itself

Tokens use Ownable2Step, custom admin roles, or proxies that answer nothing to owner(). A missing function tells you the function is missing — nothing more. That gap is exactly where a "renounced" badge can be wrong.

The test that settles it: read totalSupply() now, then again after a real interval. Growth with no matching burn is minting, whatever the code says.

สรุป

Satya Nadella ยอมรับไมโครซอฟท์มองพลาด ไม่เห็นว่า Claude Code จะมาฆ่า IDE Body Satya Nadella ซีอีโอไมโครซอฟท์ ให้สัมภาษณ์กับช่อง The Pragmatic Engineer ของ Gergely Orosz ในประเด็นว่าวิศวกรรมซอฟต์แวร์จะเปลี่ยนโฉมไปอย่างไรในยุค AI หัวข้อที่น่าสนใจคือ Nadella ยอมรับว่าไมโครซอฟท์พลาด มองข้ามการผุดขึ้นมาของระบบ AI ช่วยเขียนโค้ดอย่าง Cursor หรือ Claude Code ทำให้ซอฟต์แวร์ IDE ที่ไมโครซอฟท์ครองตลาดมาตลอด กลายเป็นไม่จำเป็นต้องมีอยู่อีกต่อไป (faded away) ภายในเวลาแค่ครึ่งปี Nadella บอกว่าเครื่องมือพัฒนาซอฟต์แวร์เป็น DNA ของไมโครซอฟท์มาโดยตลอด และบริษัทก็ปรับตัวเข้ากับยุคสมัย เช่น VS Code ที่เป็นโอเพนซอร์ส หรือ GitHub Copilot ที่เป็น AI ช่วย เขียนโค้ด แต่ไมโครซอฟท์ไม่เคยคาดว่า "AI เขียนโค้ดเองได้ทั้งหมด" แบบ Claude Code จะเข้ามาแทนที่ IDE ได้อย่างรวดเร็ว อย่างไรก็ตาม Nadella บอกว่า IDE ไม่ได้หายไป แต่มันจะกลับมาเกิดใหม่ (rebirth) ในรูปแบบอื่นแทน เขาบอกว่า IDE ยุคใหม่จะเป็นเรื่องเกี่ยวกับการใส่อินพุตสเปก และการจัดการไฟล์ markdown เขาบอกว่าปัจจุบันการสร้างโค้ด (code generation) มีราคาถูกลงมาก แต่กา

  • ทางเลือกหรือขั้นตอนที่ผู้อ่านนำไปใช้ได้
  • ข้อจำกัดและสิ่งที่ควรตรวจสอบเพิ่มเติม
  • สรุปและขั้นตอนถัดไป
